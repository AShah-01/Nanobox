Nanobox

Get the dev environment running

Five steps, one platform-specific detour for the native build tools. Click any command to copy it.

  1. 1

    Install Node.js 20+

    Nanobox's frontend (React + Vite) needs Node. Get the LTS installer from nodejs.org, or use a package manager.

    winget install OpenJS.NodeJS.LTSbrew install node
  2. 2

    Install Rust

    Tauri's core is Rust. rustup also offers to install the MSVC linker for you — accept that prompt.You'll also need the Xcode Command Line Tools (next step).

    winget install Rustlang.Rustupcurl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  3. 3

    Install the MSVC C++ Build Tools

    Required to link the Rust binary on Windows. Grab the "Desktop development with C++" workload from the Visual Studio Build Tools installer, or run:

    winget install Microsoft.VisualStudio.2022.BuildTools --override "--add Microsoft.VisualStudio.Workload.VCTools"
  4. 3

    Install Xcode Command Line Tools

    Required to link the Rust binary and build the macOS app bundle.

    xcode-select --install
  5. 4

    Clone and install

    git clone https://github.com/AShah-01/Nanobox.git
cd Nanobox
npm install
  6. 5

    Run it

    This opens the Nanobox overlay window with hot reload. First run compiles the Rust side, so it's slower than the ones after.

    npm run tauri dev

    Look for the Nanobox icon in your system tray — click it to show/hide the overlay.

Sanity check

node --version && rustc --version && cargo --version

All three should print a version. If rustc/cargo aren't found after installing, open a new terminal — PATH changes need a fresh shell.

Not a developer?

Nanobox isn't on an app store or as a packaged installer yet — running it from source with the steps above is currently the only way to use it. Once packaged builds exist, they'll be linked here and on the GitHub Releases page.
